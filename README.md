# CBS User Access Management Portal — Phase 1

GitHub-first prototype:

iOffice → i-Ticket → CBS User Access → Approval → Digital Signature → ICT Verification → Final Form → CBS/Finacle User Creation

## Run locally
npm install
npx prisma db push
npm run db:seed
npm run dev

This is a prototype. Real iOffice, i-Ticket, Finacle/CBS, SSO and production databases are NOT connected.
Do not use GitHub Pages; use GitHub for source control and an application server for the full-stack app.
